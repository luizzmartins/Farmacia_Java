# Farmácia

1. Execute `banco.sql` no MySQL 8.
2. Copie `config/db.properties.example` para `config/db.properties` e preencha o usuário e a senha do seu MySQL.
3. Abra a pasta Farmacia no IntelliJ, selecione um JDK 17 ou superior e execute o método `main` de `App.java`.

O driver JDBC fica na pasta `lib` e já está configurado no módulo do IntelliJ. Use a pasta Farmacia como diretório de trabalho.

Em um banco novo, o login inicial do programa é `admin` e a senha é `123`.
